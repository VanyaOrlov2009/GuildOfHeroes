## Собственный проект

Тема проекта: Каталог игр

Главный класс: Game

Почему этот объект нужен программе:
позволяет удобно хранить информацию об играх

Какие данные хранит объект:

- название
- жанр
- год выхода
- рейтинг


Какие значения задаются через конструктор:
название, жанр, год выхода и рейтинг

Какие значения можно задавать автоматически:
поле IsDownloaded автоматически получает значение false
